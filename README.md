# منجز — التحديثات

هذا المستودع يحوي ملفات إصدارات نظام **منجز** لإدارة الجمعيات، وملف `version.json` الذي يقرأه النظام ليعرف بتوفر تحديث.

## التنزيل
من صفحة **Releases** (الجهة اليمنى) نزّل أحدث إصدار:

- `Munjiz-Setup-<الإصدار>.exe` — مثبّت النظام. نزّل هذا الملف فقط.

## التحديث
داخل النظام يظهر شريط «يتوفر إصدار جديد» مع زر **حدّث الآن**؛ يأخذ نسخة احتياطية تلقائياً ثم يتحقق من التوقيع الرقمي للتحديث قبل تثبيته.

> هذا المستودع للتوزيع فقط ولا يحوي كود النظام ولا أي بيانات.
